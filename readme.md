# BrewBuddy

Personal beer journal for iPhone and iPad. Fully on-device — no account, no servers, no ads.

## Features

- **Library** — log beers with brewery, style, ABV, IBU, notes, and photos
- **Ratings & favorites** — 1–5 stars and quick favorites
- **Check-ins** — tastings with date, venue, note, and photo
- **Map** — globe of where you’ve drunk, with venue search via Apple Maps
- **Stats** — totals, average rating, style breakdown
- **Export** — CSV or JSON from Settings

## Requirements

iOS 17+ · Xcode 16+
